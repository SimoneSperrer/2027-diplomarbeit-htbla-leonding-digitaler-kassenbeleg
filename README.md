# 2027-diplomarbeit-digitaler-kassenbeleg
Ab 01.10.2026 wird in Österreich der digitale Kassenbeleg eingeführt. Die BMD Systemhaus GesmbH stellt mit BMD NTCS bereits Rechnungsdaten bereit, jedoch fehlt eine Lösung zur automatischen Erstellung digitaler Belege. Papierbelege überwiegen weiterhin, obwohl digitale Alternativen zunehmend gefragt sind.
